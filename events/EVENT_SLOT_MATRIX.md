**APPROVED FOR FIRST PLAYTEST**, 2026-10-26.

Канонический источник механической структуры всех 88 карт ТИ. Заменяет предварительное распределение events/EVENT_SLOTS_V1.md. **1Х** — одна характеристика; **2Х** — выбор между двумя; **СТ** — обязательные специальные эффекты стадий II и III; **—** — специальных стадийных правил нет.

Награды Доверие и Энергия означают по 1 жетону; предмет — один указанный уникальный экземпляр. Для 1Х в строке указана обычная награда. Замедление и Задержка действуют по утверждённым правилам состояний. [Общая матрица баланса](../balance/EVENT_DECK_MATRIX_V1.md).

## ПРАВИЛА ДЛЯ ПОСЛЕДУЮЩЕГО НАПИСАНИЯ СОБЫТИЙ


1. Не менять механический слот ради сюжетного текста.

Сюжет подстраивается под слот,
а не слот под сюжет.

2. Если слот говорит:

Разум 8 → Доверие,

событие должно логически объяснять,
почему применение Разума помогает героям
заслужить доверие местного народа.

3. Если карта имеет 2Х,
два варианта должны означать
два реально разных способа разрешить одну ситуацию.

Не писать два почти одинаковых действия
с разными характеристиками.

4. Если один вариант даёт более ценную сейчас награду
и имеет более высокую сложность,
сюжет должен это объяснять.

5. Предмет должен естественно присутствовать
в ситуации события.

Не использовать формулировку:
«вы просто нашли предмет»,
если можно встроить его в историю.

6. Для СТ-карт
при написании обязательно добавить
отдельные последствия / изменение ситуации
для II и III стадии нестабильности.

Не превращать это автоматически
в простой +1 к сложности.

Стадия должна по возможности менять
саму ситуацию или последствие.

7. На обычных картах без СТ
никаких специальных стадийных правил нет.

8. Для карт с Доверием
конкретный тип Доверия определяется
территорией малой клетки,
на которой расположена активированная ТИ.

9. На Диких землях
Доверие заменяется на 1 Энергию
по уже утверждённому правилу.

10. Для 1Х-карт сохраняется:

провал → последствие;

обычный успех
(равно сложности или +1)
→ указанная обычная награда;

сильный успех
(+2 и выше)
→ 1 Энергия вместо обычной награды.

Если обычной наградой уже является энергия,
всё равно выдать только 1 энергию.

11. Для 2Х:

игрок видит оба варианта,
выбирает один до броска,
при успехе получает ровно указанную награду.

Сильного успеха в 2Х нет.
