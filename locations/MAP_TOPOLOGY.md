# Топология переходов 19 больших тайлов

Утверждённые направления и двойные проходы, 2026-10-11. Общие правила движения — [RULES.md](../RULES.md), сценарии столиц — [capitals.md](capitals.md). «ВН» означает внутренний тайл и используется только в авторской документации, не на дорожных указателях.

## Направление и физический проход

**Направление** — возможность перейти на конкретный соседний большой тайл. **Физический проход** — конкретное место перехода на их общей границе. Два прохода между одной парой — одно направление, а не два.

Разные проходы ведут в разные участки соседнего 19-клеточного тайла и влияют на расстояние до точек интереса и следующего выхода, выбор локального маршрута и между быстрым продвижением и исследованием. Они могут визуально различаться, но не должны быть чисто декоративными. Множественные проходы не меняют глобальную топологию; делать их на каждой границе не требуется.

## География

Центр — Великое Древо. Внутреннее кольцо по кругу: ВН Дикие → ВН Рост → ВН Поток → ВН Искра → ВН Слово → ВН Камень → ВН Дикие.

Внешнее кольцо: Дверь → Дикие/Рост → Церея → Рост/Поток → Нереида → Поток/Искра → Ионис → Искра/Слово → Метида → Слово/Камень → Мимас → Камень/Дикие → Дверь.

Дверь — стартовый внешний тайл Диких земель. Столицы: Церея — Рост, Нереида — Поток, Ионис — Искра, Метида — Слово, Мимас — Камень. Прежняя геометрия 1+6+12 сохраняется.

## Единственный разрыв внутренней окружности

**ВН Рост ✕ ВН Поток** — единственный закрытый участок непосредственно по окружности внутреннего кольца. Остальные пять соседних пар открыты; других разрывов сейчас не делать. Граница ВН Искра ↔ ВН Слово имеет два прохода.

Рост/Поток — внешний коридор только между Цереей и Нереидой, без выходов к ВН Росту и ВН Потоку. Это сохраняет значение разрыва, не позволяя обойти его через один пограничный тайл. ВН Рост намеренно более закрыт: только Церея и ВН Дикие.

## Подходы к Древу

Только ВН Поток ↔ Древо и ВН Слово ↔ Древо открыты. Четыре остальные границы закрыты физическим рельефом; конкретные препятствия выбираются позднее. Раннее посещение Древа и отдельное условие допуска к финалу сохраняются.

## Утверждённые двойные проходы

| Пара тайлов | Характер и значение |
| --- | --- |
| Церея ↔ ВН Рост | Разные части Цереи; возможны прямой городской путь и дорога через сады / поля, точное оформление позже |
| Нереида ↔ ВН Поток | Разные участки / стороны города; вход влияет на локальное положение |
| Ионис ↔ Поток/Искра | Разные участки города; возможны главный тракт и техническая / промышленная дорога |
| Метида ↔ ВН Слово | Возможны главный тракт и старый / исторический путь; разные участки тайла |
| Мимас ↔ Камень/Дикие | Главная каменная дорога и узкий альтернативный проход между скалами; разные части Мимаса |
| ВН Искра ↔ ВН Слово | Обычный путь и необычная маготехническая дорога; разные части обоих тайлов, значимые для локального движения |

У ВН Слова **5 направлений / 7 физических проходов** по указанным данным, не прежнее черновое число 6. У ВН Диких **5 направлений / 5 проходов** по запросу; дополнительные двойные переходы здесь пока не делать.

## Проходимость столиц

Нереида разделена крупным руслом. До «Старого русла» нельзя свободно перейти с одной стороны на другую; вход определяет сторону / участок города. **Ключевая задача достижима независимо от выбранного входа**, без тупикового состояния. После задачи физический мост / переправа соединяет части города. Открытая межтайловая граница не отменяет препятствий внутри города.

Ионис изначально проходим, стабилизация не открывает новую глобальную дорогу. Метида и Мимас изначально проходимы; их стабилизация не обязана открывать новую дорогу. Физические изменения столиц и остальные правила не меняются.

Количества проходов в текущей таблице полностью определены. У Поток/Искра утверждены 1 к Нереиде, 2 к Ионису, по 1 к ВН Потоку и ВН Искре. Добавление новых двойных проходов требует отдельного решения.

## Локальная проходимость

Внутри любого большого тайла движение разрешено по всем соседним маленьким гексам при проходимой целевой клетке и отсутствии непроходимой общей границы. Дороги не ограничивают доступное пространство: они служат навигации, атмосфере, маршрутам и композиции. Полностью запрещённые клетки и непроходимые стороны между клетками обозначаются раздельно и однозначно; пересечение преград возможно через явно обозначенные специальные переходы. Разная стоимость движения по местности не вводится.

Этот принцип применяется ко всем 19 тайлам, включая Нереиду. Он не добавляет межтайловых связей: утверждённые направления, физические проходы и групповой порядок перехода сохраняются. При раскладке двойных проходов их значение проверяется с учётом свободного движения вне дорог. Полные правила — [RULES.md](../RULES.md).
