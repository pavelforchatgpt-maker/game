# Геометрический валидатор карты

Нужен Node.js; внешних пакетов нет.

```text
node tools/map_validator.cjs
node tools/map_validator.cjs --report
node tools/map_validator_test.cjs
```

Первый запуск только проверяет данные и возвращает 0 при соблюдении жёстких инвариантов, 1 при нарушениях. Второй также перезаписывает только отчёт MAP_AUDIT.md, приложение MAP_AUDIT_ROUTES.csv и tools/map_audit_results.json. Канонические документы не изменяются.

map_data.cjs — отдельная транскрипция канона для аудита, не новый источник геймдизайнерских решений. Источник каждого тайла указан в поле source. map_sources.json содержит SHA-256 исходников с нормализованными переносами строк. При изменении исходника проверка останавливается: сначала вручную сверить геометрию и модель, затем явно обновить соответствующий хеш. Автоматического принятия новых координат нет. Ошибку ручной транскрипции контроль хешей сам по себе не обнаруживает.

Тесты внедряют ошибки только в память отдельных дочерних процессов: неверное ребро, зеркало, закрытый переход, преждевременный мост, блокированный вход, POI на выходе и исчезнувший постоянный мост. Данные на диске не меняются.

Программа не моделирует броски, групповые активации, помощь и баланс наград. Число больших переходов и локальные шаги — отдельные метрики. Маршруты +1/+2 перечислены как прогулки с возможными повторениями тайлов; физические двойные переходы не считаются разными макромаршрутами. Сравнение по малым шагам включает посещение ключевой проблемы каждой столицы, предполагает успех и открытие моста A-5; дополнительные задачи и стоимость решения не включены.
