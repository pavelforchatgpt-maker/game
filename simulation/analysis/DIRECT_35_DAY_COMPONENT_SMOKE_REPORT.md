# Первичный аудит вклада механик и личных талантов — 3 игрока, 35 суток

Дата: 11 ноября 2026 года.

**СТАТУС: ДИАГНОСТИЧЕСКАЯ ПРОВЕРКА, НЕ УТВЕРЖДЕНИЕ БАЛАНСА.**

## Проверенная база

Три героя, одна обычная групповая активация в сутки (кроме собственной возможности способности №9 «Сквозь время»), **35 суток**, правило А — остаток движения после ТИ, активный поиск по 1 Доверию у народов, −3 сложности задач столиц, три масштабированные стадии 1–14 / 15–26 / 27–35, `ST-NEUTRAL`, обычная случайность, глобальный маршрутный оптимизатор. Предыдущая основная оценка на 1024 партиях без талантов — **48,0% побед**, ~18 ТИ в успешной партии. Никакие канонические правила не менялись.

## Реально выполненный прямой компонентный тест

Из-за того что новые задачи GitHub Actions на момент аудита оставались в статусе `queued`, код текущего репозитория был загружен через подключение GitHub и **выполнен непосредственно в V8** с минимальными совместимыми оболочками для CommonJS, `structuredClone` и встроенных модулей Node. Это **второй способ исполнения**, а не независимая проверка в штатном Node: исходные модульные файлы и механика не переписывались, но некоторые системные API подменены совместимыми реализациями.

**Одинаковые начальные 32 seed: 24100000–24100031; одни и те же составы из 3 героев.** Последующие генерации карт/кубиков могут расходиться, когда траектория меняется. Сравнение небольшое и служит диагностикой, а не достоверной оценкой винрейта.

| Режим | Победы из 32 | ТИ за партию (все) | Средняя обычная помощь на ТИ |
|---|---:|---:|---:|
| Всё доступно (таланты отключены) | 19/32 = **59,4%** | 19,34 | **18,81** |
| Без обычной помощи союзника в ТИ | 4/32 = **12,5%** | 24,69 | 0 |
| Без всех эффектов магических способностей | 4/32 = **12,5%** | 19,09 | 18,66 |
| Без применения предметных бонусов | 19/32 = **59,4%** | 19,34 | 18,81 |
| Вместо случайного +1: личный талант по синтетическим тегам | 20/32 = **62,5%** | 19,53 | 19,03 |

**Основное механическое наблюдение:** базовый авто-планировщик на этих seed находит легального помощника практически для каждой ТИ — **18,81 помощи при 19,34 ТИ, ~97% посещений**. Сотрудничество очень сильно влияет на вероятность успеха. Магические способности также имеют крупный вклад (модель автоматически выбирает выгодную из трёх предложенных). Это ещё не означает, что аналогичный эффект будет в партиях реальных людей: стратегия автоматически выбирает выгодные маршруты и активирует доступную помощь.

**Предметы:** в серии из 32 сценариев они фактически не поменяли исходов; это не доказательство их бесполезности. Ранее более широкая серия из 512 партий показывала ~1,3 применения предметного эффекта на партию. В ранних 32 сценариях предметная добыча была особенно редкой, около 0,06–0,09 успешных получений предметов в среднем на партию (в разных контрфактах).

### Статистическое ограничение

На 32 партиях интервалы очень широки, особенно по винрейту. Не интерпретировать 59,4%, 62,5% и 12,5% как точные вероятности для пользователей или как окончательное преимущество. Проверенный ранее результат 48% на 1024 партиях без талантов остаётся более надёжным ориентиром для **конкретной алгоритмической модели**.

## Новая диагностическая модель 12 талантов

Для 88 существующих карточек и 127 альтернативных путей проверки создана отдельная черновая таблица `simulation/analysis/SYNTHETIC_TALENT_TAGS_88.json`:

- все **88 карточек** сохранены, атрибуты всех **127 проверочных путей** сохранены без изменений;
- на каждый путь назначен один или два *гипотетически подходящих* таланта из утверждённого набора;
- **по всем 12 талантам — от 10 до 14 возможностей**, без нарушения совместимости с характеристикой;
- каждая карточка осталась механически той же; данные не переносятся в канонические `events/EVENT_SLOT_MATRIX.md`, `simulation/config.json` и `RULES.md`;
- этот набор является **синтетической гипотезой**, так как художественные ситуации ещё не написаны. Он не заменяет настоящую разметку по сюжетам.

В экспериментальном движке теперь работает отдельная включаемая опция `talentModel:'synthetic'`, которая:

1. даёт конкретному герою один выбранный талант перед началом (стратегия `rational` или `cyclic`);
2. проверяет соответствие его таланта назначенному тегу конкретной карты и выбранной характеристики;
3. начисляет +1 только при соответствии, без произвольного броска «активировать талант»;
4. поддерживает №13 **«Общий талант»**: союзник той же группы в пределах 3 клеток передаёт свой подходящий талант один раз за сутки.

В 32 контрольных сценариях с `rational` было в среднем **2,53 личных срабатывания таланта** на партию, без срабатываний №13 (способность №13 почти не выбирается рациональным агентом из случайного предложения, где её приоритет последним).

### Отдельная проверка способности №13

В 12 специальных контрольных партиях принудительно задавались магические способности `[13,8,16]` и таланты `[9,1,3]` при включённом синтетическом теге. Способность №13 активировалась **12 раз суммарно за 12 партий**; в отдельных партиях 0–3 раза. Это подтверждает работу механики передачи подходящего таланта в диагностическом режиме, **но не полноту будущих сюжетных условий**.

## Ограничения, которые пока не закрыты

- Все 88 событий ещё не имеют законченных сюжетных ситуаций. Подходящие таланты должны вытекать из реального действия, а не из черновых ID.
- 15 проблем столиц пока не получили полную проверку ситуационного применения талантов.
- №18 «Чувство пути» реализована упрощённо: агент просматривает тайл, но не выбирает отказ от перехода.
- Симулятор автоматически выбирает магические способности по приоритету и почти всегда использует доступную помощь. Это сильная, не обязательно типичная семья.
- Ранее утверждённый ориентир **23–26 ТИ** для трёх игроков ещё не выполнен: при 35 сутках получается примерно 17–18 ТИ в победных партиях. Идёт отдельная проверка более плотного исследования, без бонусных активаций.
- 29 событий с отдельными эффектами стадий ещё сведены к условным числовым ST-сценариям; настоящий сюжетный баланс может отличаться.
- Время игры — расчёт по действиям, а не настольный плейтест.
