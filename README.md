# Семейная кооперативная фэнтези-настольная игра

Репозиторий — единый источник истины для правил, мира, персонажей, событий, предметов и баланса, позднее — цифрового прототипа. Название игры пока не определено.

Базовая игра: **2–4 игрока, примерно от 9 лет, без ведущего, 120–150 минут**. Один игрок — один герой. В основе путешествие, скрытая карта, совместные решения и попытка вернуться домой через восстановление мира.

## Порядок работы

Крупные механики сначала обсуждаются и утверждаются пользователем, затем фиксируются. Утверждённое меняется только по его прямому указанию. При пробеле или противоречии описываем вопрос; неизвестное не становится правилом автоматически. Программный прототип не разрабатывается без отдельного решения.
