# Семейная кооперативная фэнтези-настольная игра

Репозиторий — единый источник истины для разработки правил, мира, персонажей, событий, предметов и баланса, а в будущем — цифрового прототипа. Название игры пока не определено.

Игра рассчитана прежде всего на семейное прохождение втроём, без ведущего. В основе — путешествие, постепенное исследование фэнтезийного мира и развитие героев.

## Документы

| Файл | Назначение |
| --- | --- |
| [PROJECT_BRIEF.md](PROJECT_BRIEF.md) | Полный структурированный контекст и ограничения проекта |
| [GAME_DESIGN.md](GAME_DESIGN.md) | Каркас геймдизайн-документа и статус разделов |
| [RULES.md](RULES.md) | Известные игровые положения и единый список открытых вопросов |
| [WORLD.md](WORLD.md) | Утверждённые сведения о мире |
| [DECISIONS.md](DECISIONS.md) | Журнал принятых решений с причинами и связями |

## Папки

| Папка | Назначение |
| --- | --- |
| characters/ | Персонажи |
| traits/ | Черты характера |
| talents/ | Способности и таланты |
| items/ | Предметы |
| events/ | События и их последствия |
| encounters/ | Встречи и столкновения; граница с событиями ещё не определена |
| locations/ | Локации и тайлы |
| balance/ | Расчёты и материалы проверки баланса |
| prototype/ | Место для будущего цифрового прототипа |

Файлы .gitkeep сохраняют пока пустые папки при добавлении в Git. Программный прототип пока не разрабатывается.

## Порядок работы

Крупные механики сначала обсуждаются и утверждаются пользователем, затем фиксируются в документации. Утверждённые решения меняются только по его прямому указанию. При пробеле или противоречии сначала описываем проблему и задаём вопрос.

Исходные ограничения собраны в PROJECT_BRIEF.md, игровые положения — в RULES.md, сведения о мире — в WORLD.md; DECISIONS.md хранит историю решений. GAME_DESIGN.md связывает разделы. Неизвестное обозначается явно и не становится правилом без утверждения.
